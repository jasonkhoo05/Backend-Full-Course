# 2) Install Express.js
npm install express

package.json contains all the specification for the project.

# This package is so that when you make changes, you don't need to restart the server
# It is a developer dependency, meaning it should not used in production, it's specifically for development only
npm install --save-dev nodemon

# now "dev": "node server.js" becomes "dev": "nodemon server.js" in package.json

Endpoints: HTTP VERBS (method) and Routes (paths)
http://localhost:3000/dashboard
dashboard is the route

We can define actions at these endpoints that execute a body of logic
to respond appropriately to network requests

We need to configure these routes to interpret specific verbs such as GET
to help us understand the intention of the network request

-----------------------------------------------------------------------------
There are 2 types of endpoints: Website endpoint and API endpoint


Website endpoints are for sending back HTML and they typically come when a user enters a 
URL in a browser

API endpoints are non-visual 
E.g. when a user press submits for their username and password
